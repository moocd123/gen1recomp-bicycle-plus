# Bicycle Plus v1.4.0

**v1.4.0 is the first public release of Bicycle Plus.**

## Highlights

- Automatic cycling when entering eligible areas while carrying the Bicycle.
- Manual-dismount memory for the current area.
- Five independent bicycle colour controls: **WHEEL, STRIPE, CENTRE, EDGE and DETAILS**.
- Animated bicycle preview while preserving the original 16×16 sprite grid and native animation.
- Separate normal and cycling audio profiles.
- **BICYCLE, AREA or BOTH** music while riding.
- Independent area/bicycle music volumes and filters plus cycling-specific SFX controls.
- Compatibility work for Trainer Skins and several commonly used Gen1ReComp++ mods.
- Supports Pokémon Red, Blue, Yellow, Gold, Silver and Crystal on Gen1ReComp++ v0.2.59.
- Intended to work across platforms supported by Gen1ReComp++ v0.2.59.

## Installation

Download `Bicycle_Plus-1.4.0-Gen1ReComp-0.2.59.zip`, leave it zipped, and import it from the Gen1ReComp++ launcher under **MODS**.

Enable Bicycle Plus for each game edition you use, then launch the game and open **OPTION/OPTIONS → BICYCLE +**.

No ROMs or ROM data are included in this release.
